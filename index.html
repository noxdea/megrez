One session, ordered.

Megrez owns the protocol state machine so a host can focus on its debugging experience. Requests remain cancellable and events arrive in adapter order.

Full execution control

Launch, attach, break, continue, step, pause, evaluate, and inspect through one Ruby API.

Safe references

Stop generations reject stale variable references before they can query invalid debugger state.

Adapter-ready

Use stdio or TCP, handle reverse requests, and test locally with the bundled fake adapter.

Open a session.

Start any DAP-compatible adapter and wait only where your application needs to.

Ruby
$ bundle add megrez

session = Megrez::Session.stdio(
  command: ["adapter", "--stdio"]
)
session.start(adapter_id: "ruby")
session.launch("program" => "app.rb")
